# Entreg-vel_techX

O projeto consiste em uma **aplicação digital para verificar a confiabilidade de informações**. O usuário insere uma notícia, afirmação ou conteúdo no sistema, que analisa a informação e consulta fontes confiáveis. Ao final, a aplicação indica se a informação é **verdadeira ou possivelmente falsa**, apresenta as evidências e as fontes utilizadas. Caso seja falsa, o sistema também alerta o usuário e apresenta informações corrigidas, ajudando a **combater a desinformação e incentivar o consumo consciente de conteúdo na internet**.
